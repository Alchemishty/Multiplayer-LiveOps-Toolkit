# Showcase credits

The SDK showcase uses the Full Demo character and cosmetic assets, presented in a staged studio with custom lighting, cameras, typography and editing. The footage records real SDK operations against a disposable instance of the reference backend.

Character and cosmetics: [Amir – Low Poly Modular Characters (Free)](https://ahmedamirdev.itch.io/amir-low-poly-modular-characters) by **Amir / Ahmed Amir**, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Presentation changes include lighting, camera composition and exclusion of unused decorative props bundled in the outfit prefabs.

Palette textures: [Imphenzia](https://imphenzia.com/).
